# Cardory 手工验收清单

记录每项的通过/失败、测试时间、设备和截图证据。失败项修复后重新执行对应场景。

## 用户流程

- [ ] 首次进入：隐私说明可见，拒绝/同意行为符合预期
- [ ] 登录失败：不进入签到、抽卡或卡册功能
- [ ] 北京时间跨日：签到状态在 00:00 后正确刷新
- [ ] 重复签到：同一天只能增加 1 次抽卡次数
- [ ] 单抽：余额扣 1，结果展示图片/占位和稀有度
- [ ] 十连：余额扣 10，十张结果和汇总均可查看
- [ ] 余额不足、卡池为空、接口失败：不改变余额或卡册
- [ ] 重复 `requestId`：返回同一结果且不重复扣次数
- [ ] 卡册：筛选、收集进度、重复数量和未获得剪影正确
- [ ] 图片加载失败：显示占位图且卡牌信息保留

## 规则与安全

- [ ] 保底边界按当前发布配置执行
- [ ] 限定卡开始前/结束后状态正确
- [ ] 普通下架卡仅对已拥有用户保留
- [ ] 强制移除卡对所有普通用户隐藏且不计入总数
- [ ] 普通用户伪造管理员请求返回 `FORBIDDEN`
- [ ] 签到、抽卡并发/失败后余额、保底、收藏和流水一致
